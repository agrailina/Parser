# Парсер контактной информации сайтов

Этот проект представляет собой парсер, который принимает стартовый URL, обходит страницы сайта и возвращает контактные данные, найденные на сайте.

## 📋 Особенности

- **Обход сайта:** Автоматически обходит до 10 страниц в пределах одного домена
- **Поиск email:** Находит email адреса в тексте и mailto ссылках
- **Поиск телефонов:** Обнаруживает номера телефонов в тексте и tel ссылках
- **Нормализация данных:** Приводит телефоны к единому формату
- **Защита от дубликатов:** Использует множества для хранения уникальных значений
- **Фильтрация ссылок:** Пропускает битые ссылки и файлы (изображения, документы и т.д.)

## 🛠️ Стек технологий

- **Python 3.11+** - основной язык программирования
- **Requests** - для выполнения HTTP-запросов
- **BeautifulSoup4** - для парсинга HTML
- **re** - для работы с регулярными выражениями
- **urllib** - для работы с URL

## ✨ Функциональность

### 🔍 Поиск email адресов
- Извлечение email из `mailto:` ссылок
- Поиск email в тексте страницы с помощью регулярных выражений
- Валидация найденных email адресов
- Удаление дубликатов

### 📞 Поиск номеров телефонов
- Извлечение телефонов из `tel:` ссылок
- Поиск российских номеров телефонов в тексте
- Нормализация формата номеров
- Преобразование форматов (8... → +7...)

### 🌐 Обход сайта
- Ограничение обхода доменом стартового URL
- Максимум 10 страниц для предотвращения бесконечного обхода
- Избегание циклических ссылок
- Пропуск не-HTML контента
- Фильтрация файлов (PDF, изображения, архивы и т.д.)


## 🚀 Установка и запуск

### 1. Установите зависимости:

```bash
pip install -r requirements.txt
```
### 2. Запустите программу:

```bash
python contact_parser.py
```
